A robust, feature-rich E-Commerce web application built with Python, Django 5, and MySQL, designed for a seamless online shopping experience with advanced product categorization, secure user management, and Persian localization.

Framework: Powered by Django 5.2 (Latest stable version) for high performance.
Database: Robust data management using MySQL.
Modern UI: Clean and responsive user interface using Bootstrap 5 and Crispy Forms.
E-Commerce Features

User Management: Secure authentication and profile management via django-allauth.
Dynamic Shopping Cart: Session-based cart system for smooth user experience.
Product Catalog: Advanced product categorization with specific technical specs (Laptop, Mobile, Camera) and discount management.
Order Processing: Efficient system for handling customer orders and order items.
Admin & Localization

Admin Dashboard: Sleek, modern, and user-friendly management panel powered by django-jazzmin.
Persian Localization: Full support for the Jalali (Solar) calendar system (django-jalali-date) throughout the dashboard and customer-facing pages.
Data & Media: Intelligent image processing (Pillow) and Excel data handling (openpyxl) for administrative tasks.
